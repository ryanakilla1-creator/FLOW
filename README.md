# FLOW Aim Trainer

Aplicativo Android independente para praticar precisão de toque em alvos.

## O que inclui
- Projeto Android em Kotlin + Jetpack Compose.
- Contador de pontos e alvos acertados.
- Seletor visual de formato do alvo (cabeça/ombro) para exercícios.
- Botão para iniciar e pausar a sessão.

## Limites
O FLOW não se injeta no Free Fire, não altera a mira do jogo, não lê memória/processos, não detecta jogadores e não implementa aimbot ou ESP. O seletor de formato só muda o alvo de treino dentro deste aplicativo.

## Como compilar
1. Abra este repositório no Android Studio.
2. Aguarde a sincronização do Gradle.
3. Use JDK 17 e Android SDK 35.
4. Selecione a configuração `app` e execute em um dispositivo Android ou emulador.

Package: `com.flow.aimtrainer`
